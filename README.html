ConfigDebian - Documentação Completa

1️⃣ Instalação do Sistema

Para instalar o sistema em uma VPS nova (Debian/Ubuntu), siga estes passos:

  1. Baixe o setup_vps.sh diretamente do repositório:
    2. wget https://raw.githubusercontent.com/jutair/configdebian/main/setup_vps.sh -O setup_vps.sh
  2. Garanta que ele está com permissão de execução:
    3. chmod +x setup_vps.sh
  3. Execute como root:
    4. sudo ./setup_vps.sh

O script fará automaticamente:

  • Instalação de pacotes essenciais (vnstat, ufw, fail2ban, openvpn, samba, speedtest-cli, bc, sudo, curl, wget, unzip)
  • Criação dos usuários jutair e guest com login via chave SSH do root
  • Download de todos os scripts ConfigDebian para /opt/configdebian
  • Configuração do menu automático ao logar

2️⃣ Estrutura de Scripts

setup_vps.sh

Script principal para setup inicial. Faz o download do repositório e executa configura_sistema.sh automaticamente.

configura_sistema.sh

Script responsável por:

  • Instalar pacotes essenciais
  • Baixar e atualizar scripts ConfigDebian do GitHub
  • Baixar o openvpn-install.sh oficial na pasta /opt/configdebian
  • Criar usuários jutair e guest com diretórios e permissões corretas
  • Configurar login automático para abrir menu.sh ao acessar via SSH

menu.sh

Painel interativo principal que exibe:

  • IP externo, usuários SSH ativos, uso de RAM, disco, uptime
  • Banda consumida pela interface VPN (tun0)

Possui opções interativas:

1️⃣ Gerenciar VPN - Executa open_vpn_conf.sh para criar/remover usuários VPN, gerar arquivos .ovpn, visualizar usuários online.
2️⃣ Gerenciar Rede e Segurança - Executa gerencia_rede.sh para configurar firewall, fail2ban, SSH e regras de rede.
3️⃣ Gerenciar Usuários do Sistema - Executa usuarios.sh para criar/remover/editar usuários Linux e grupos.
4️⃣ Atualizar Sistema - Executa update_sistema.sh para atualizar o sistema, scripts ConfigDebian e openvpn-install.sh.
5️⃣ Backup do Sistema - Executa backup.sh para criar backup de /home e /opt/configdebian.
6️⃣ Sair - Encerra o menu.

open_vpn_conf.sh

Permite gerenciar usuários OpenVPN, visualizar usuários conectados, gerar arquivos .ovpn para download e verificar tráfego por usuário.

gerencia_rede.sh

Configura segurança de rede: firewall (UFW), fail2ban, portas SSH e regras de VPN.

usuarios.sh

Criação, remoção e gerenciamento de usuários do sistema, incluindo permissões sudo e diretórios de backup.

update_sistema.sh

Atualiza o sistema, pacotes e scripts ConfigDebian do GitHub. Também garante que openvpn-install.sh esteja atualizado na pasta /opt/configdebian.

backup.sh

Cria backup completo das pastas /home e /opt/configdebian em um arquivo compactado no diretório /root/backups.

3️⃣ Funcionalidades do Sistema via Menu

O menu interativo simplifica todas as operações administrativas:

  • Visualizar o estado da VPS em tempo real (RAM, disco, uptime, usuários conectados)
  • Gerenciar VPN e arquivos de clientes (.ovpn) facilmente
  • Gerenciar usuários Linux sem precisar memorizar comandos
  • Gerenciar rede e segurança (firewall, fail2ban) de forma centralizada
  • Atualizar sistema e scripts com um clique
  • Gerar backup completo do sistema rapidamente

4️⃣ Requisitos

  • Debian ou Ubuntu 20.04/22.04
  • Acesso root
  • Conexão à Internet para download dos scripts e pacotes

5️⃣ Conclusão

Após rodar setup_vps.sh em uma VPS limpa, o usuário apenas precisa logar via SSH com jutair ou guest. O menu.sh será carregado automaticamente, permitindo gerenciar VPN, rede, usuários, atualizações e backup de forma simples e segura.
