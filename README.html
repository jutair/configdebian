ConfigDebian - Painel de Gestão VPS

ConfigDebian é um conjunto de scripts para automatizar a gestão de VPS Debian/Ubuntu. Inclui:

  • Menu interativo com cores e ícones
  • Gerenciamento de VPN OpenVPN
  • Controle de usuários SSH
  • Firewall e segurança (UFW, Fail2Ban)
  • Backup e atualizações automáticas

Setup Automático em VPS Nova

O fluxo ideal para uma VPS limpa é executar apenas o script setup_vps.sh:

  1. Baixar o script: 
    wget -O setup_vps.sh https://raw.githubusercontent.com/jutair/configdebian/main/setup_vps.sh
  2. Dar permissão de execução: 
    chmod +x setup_vps.sh
  3. Executar como root: 
    sudo ./setup_vps.sh
  4. O script fará:
    • Instalação de dependências essenciais
    • Criação dos usuários jutair e guest
    • Cópia da chave SSH do root para esses usuários
    • Download de todos os scripts para /opt/configdebian
    • Configuração para iniciar o menu automaticamente no login
  5. Após isso, basta logar como jutair ou guest para acessar o menu automaticamente.

Estrutura de Scripts

  • menu.sh - Painel de gestão principal
  • open_vpn_conf.sh - Gerenciamento OpenVPN
  • gerencia_rede.sh - Configuração de firewall, rede e segurança
  • usuarios.sh - Gerenciamento de usuários do sistema
  • update_sistema.sh - Atualização de sistema e scripts
  • configura_sistema.sh - Configuração inicial de VPS e usuários
  • backup.sh - Backup automático do sistema e arquivos importantes
  • openvpn-install.sh - Script oficial do OpenVPN (baixado automaticamente)

Menu Principal - Detalhes de Cada Opção

=============================================================== PAINEL DE GESTÃO VPS - DIGITALOCEAN =============================================================== [1] 🌐 Gerenciar VPN (OpenVPN) [2] 🚀 Gerenciar Rede e Segurança (FW/SSH) [3] 👤 Gerenciar Usuários do Sistema [4] 🆙 Atualizar Sistema [5] 💾 Backup do Sistema [6] ❌ Sair ---------------------------------------------------------------

Descrição das opções:

  • 1 - Gerenciar VPN (OpenVPN): Abre o script open_vpn_conf.sh, permitindo criar/remover usuários VPN, gerar arquivos .ovpn, visualizar usuários online e consumo de banda.
  • 2 - Gerenciar Rede e Segurança (FW/SSH): Chama gerencia_rede.sh para configurar firewall (UFW), fail2ban, regras de SSH e proteção da VPS.
  • 3 - Gerenciar Usuários do Sistema: Chama usuarios.sh para adicionar, remover ou modificar usuários Linux e permissões sudo.
  • 4 - Atualizar Sistema: Executa update_sistema.sh que atualiza o sistema operacional, scripts do GitHub e o script oficial openvpn-install.sh.
  • 5 - Backup do Sistema: Executa backup.sh, criando backup completo das pastas /home e /opt/configdebian em arquivo .tar.gz com data.
  • 6 - Sair: Encerra o menu e retorna ao shell.

Notas Importantes

  • Todos os scripts ficam em /opt/configdebian.
  • Usuários jutair e guest são criados automaticamente.
  • O menu inicia automaticamente no login desses usuários.
  • Setup completo é feito com setup_vps.sh para VPS nova.
  • Permissões de execução são configuradas automaticamente para todos os scripts.
